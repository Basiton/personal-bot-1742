# ✅ Чек-лист: Добавление аккаунтов через Auth Key/tdata

## Перед началом

- [ ] Python 3.7+ установлен
- [ ] `telethon` установлен (`pip install telethon`)
- [ ] Для tdata: `opentele` установлен (`pip install opentele`)
- [ ] Бот запущен и работает

## Способ 1: Auth Key → StringSession

### Подготовка
- [ ] У вас есть Auth Key (512 HEX символов)
- [ ] Вы знаете DC ID аккаунта (обычно 2)
- [ ] Есть прокси (опционально)

### Конвертация
- [ ] Запустили: `python3 convert_session.py`
- [ ] Выбрали: `1` (Auth Key)
- [ ] Вставили Auth Key
- [ ] Указали DC ID
- [ ] Указали прокси (если нужен)
- [ ] Получили файл `session_converted.json`

### Добавление в бота
- [ ] Скопировали StringSession из файла
- [ ] Выполнили в боте: `/addaccount +номер StringSession Имя [прокси]`
- [ ] Получили сообщение "✅ Аккаунт успешно добавлен!"
- [ ] Проверили: `/listaccounts`
- [ ] Видите аккаунт со статусом 🔵 RESERVE

### Активация
- [ ] Выполнили: `/toggleaccount +номер`
- [ ] Статус изменился на ✅ ACTIVE
- [ ] Проверили: `/listaccounts`

## Устранение проблем

### Auth Key не работает
- [ ] Попробовали другой DC ID (1-5)
- [ ] Проверили длину (должно быть 512 символов)
- [ ] Проверили что это HEX (только 0-9, a-f)

### tdata не конвертируется
- [ ] Закрыли Telegram Desktop
- [ ] Установили: `pip install opentele`
- [ ] Проверили путь к tdata
- [ ] Проверили что в tdata есть аккаунты

### Прокси не работает
- [ ] Формат: `тип:хост:порт:юзер:пароль`
- [ ] Тип: socks5, socks4 или http
- [ ] Прокси действительно работает
- [ ] Проверили подключение отдельно

### Аккаунт не активен
- [ ] Выполнили: `/toggleaccount +номер`
- [ ] Проверили статус: `/listaccounts`
- [ ] Если BROKEN: `/toggleaccount` ещё раз

## Безопасность
