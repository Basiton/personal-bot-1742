# personal-bot-1742

Telegram бот для автоматизации комментирования с расширенными функциями управления профилями.

## 🆕 Добавление аккаунтов через Auth Key / tdata

**Новинка!** Теперь можно добавлять аккаунты **без SMS кода**:
- ✅ **Auth Key (HEX)** - прямой импорт ключа авторизации
- ✅ **tdata** - импорт из Telegram Desktop
- ✅ **Поддержка прокси** - для каждого аккаунта свой прокси
- ✅ **Российские номера** - работает с +7 без проблем

### 🚀 Быстрый старт (новый способ):

```bash
# 1. Конвертируйте Auth Key или tdata в StringSession
python3 convert_session.py

# 2. Добавьте аккаунт в бота (с прокси)
# В боте:
/addaccount +79991112233 StringSession_здесь Имя socks5:host:1080:user:pass

# 3. Активируйте
/toggleaccount +79991112233
```

## 🎯 Управление профилями аккаунтов

Интерактивная система управления профилями Telegram-аккаунтов прямо из бота!

### Возможности:
- ✅ **Динамическое управление** любым количеством аккаунтов
- ✅ **Загрузка аватарок** через бота
- ✅ **Редактирование имени и фамилии**
- ✅ **Изменение информации о себе (био)**
- ✅ **Автоматическая пагинация** для больших списков
- ✅ **Превью перед применением** всех изменений

### 🚀 Быстрый старт (классический способ):

```bash
# 1. Настройте переменные окружения
export ACCOUNT_1_PHONE="+1234567890"
export ACCOUNT_1_SESSION="session_string..."
# ... и так далее

# 2. Запустите бота
python3 main.py

# 3. В боте используйте команду
/accounts
```
