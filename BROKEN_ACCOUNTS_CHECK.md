# 🔍 Быстрая проверка: Автоматическая пометка сломанных аккаунтов

## ✅ Что было  исправлено

Теперь бот **автоматически** помечает аккаунты как `broken` при обнаружении критических ошибок Telegram:

### Критические ошибки:
- 🚫 **UserDeactivated** - аккаунт деактивирован/удален Telegram
- 🔑 **AuthKeyUnregistered** - ключ авторизации недействителен  
- 🔑 **SessionRevoked** - сессия отозвана
- ⛔ **PhoneNumberBanned** - номер телефона забанен Telegram
- ❌ **Not authorized** - потеряна авторизация

## 🧪 Как проверить

### 1. Посмотрите текущие аккаунты:
```
/listaccounts
```

Вы увидите:
- ✅ = ACTIVE (активные)
- 🔵 = RESERVE (резервные)
- 🔴 = BROKEN (сломанные)

### 2. Мониторьте логи:
```bash
tail -f bot_logs.txt | grep -E "BROKEN|DEACTIVATED|BANNED"
```

При обнаружении сломанного аккаунта вы увидите:
```
🚫 [Account1] ACCOUNT DEACTIVATED BY TELEGRAM!
   Marking as BROKEN...
✅ Replaced broken account: Account1 → Account2
```

### 3. Проверьте инциденты:
```
/incidents
```

Покажет историю всех критических ошибок с аккаунтами.

## 📱 Что происходит автоматически

1. **Обнаружение:** Бот обнаруживает критическую ошибку
2. **Пометка:** Аккаунт автоматически помечается как `BROKEN`
3. **Замена:** Система активирует резервный аккаунт  
4. **Уведомление:** Вы получаете сообщение в Telegram
5. **Продолжение:** Комментирование продолжается без простоя

## 📊 Пример уведомления

Когда аккаунт ломается, вы получите сообщение:

```
🔥 Горячая замена после бана

🔴 Забанен: Account1 (+1234567890)
Причина: Account deactivated: UserDeactivatedBanError

✅ Активирован: Account2 (+0987654321)
🔄 Worker перезапущен в слоте 0
📢 Каналов: 50

📊 Состояние: {'active': 2, 'reserve': 1, 'broken': 1}

✅ Комментирование продолжается без простоя!
```

## 🛠️ Команды диагностики

- `/listaccounts` - список всех аккаунтов и их статусов
- `/incidents` - история критических ошибок
- `/stats` - общая статистика работы
- `/toggleaccount +номер` - вручную изменить статус (если нужно)
- `/auth +номер` - попробовать восстановить сломанный аккаунт
